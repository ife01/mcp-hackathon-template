# Quick start

Follow the repository README for installation, local stdio/HTTP operation, tests,
and frozen tool evaluation. The package is `resp_mcp` and the entry point is
`resp_mcp.server:main` (or `uv run python main.py`).

Before connecting an agent, read docs/METHODS.md. Use docs/WXO_AGENT_SETUP.md for
wxO registration and the required credentials. Do not treat successful local
checks as proof of a live wxO connection.
