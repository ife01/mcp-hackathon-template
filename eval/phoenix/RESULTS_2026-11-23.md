## Initial errors and grading corrections

The initial run completed all agent tasks but had 17 rate-limited judge calls.
Those calls had no passing scores.
The resume command repeated only missing judge calls, with request spacing and bounded retry.
It preserved all original agent outputs and task IDs.

Three answers also failed the original numeric checker incorrectly:

- P02: the checker rejected valid four-decimal rounding of a returned relative change.
- P11: an outage result omitted its date, but the actual tool arguments supplied the cited cutoff.
- P13: the checker treated the digits in `COVID-19` as a numerical surveillance claim.

The corrected checker accepts rounding through six decimals and actual call-argument evidence.
It excludes digits in the pathogen names `COVID-19` and `SARS-CoV-2`.
Regression tests cover all three cases and still reject an unsupported number.
Semantic judges still assess source, date, unit and geographic attribution.

The three affected public health scores received new semantic judgments.
Previously successful public health judgments were reused and marked as such.
The public evidence preserves the original 17 errors and three false numeric failures.
No benchmark questions, expected answers, frozen records or agent responses changed.

## Interpretation and limits

This run supports correct tool use and descriptive answers for these 15 questions.
It includes historical abstention, derived wastewater classifications, regional scan totals,
source outages, typo recovery, individual-risk refusal and publication-vintage limits.

Both roles used the same model, which can bias semantic judgments.
Only one repetition ran. No no-tool comparison or separate holdout ran.
Grader corrections followed inspection of these cases.
The result therefore does not establish unseen-case performance or measured MCP tool lift.
Independent human review remains necessary, especially for material caveats.
The project does not demonstrate validated forecasts, clinical predictions or analyst time savings.

## Repeat or resume

Use the configuration and smoke commands in README.md before another model run.
To recover incomplete judge scores without new agent calls:

```shell
uv run python scripts/resume_phoenix_judges.py --experiment-id YOUR_EXPERIMENT_ID
```

For the documented numeric correction on this original experiment, add
`--repair-numeric-grading`. Do not use this flag to hide or replace genuine failures.
The command retains original local files and writes a separate resumed result.
